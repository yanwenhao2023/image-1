# 诗经集 · 1000 首经典诗词离线版

在原《诗经集》目录版基础上，把占位目录全部替换为**真实的经典诗词正文**。

## 本版主要升级

- **内置 1000 首真实经典诗词**（全部为公有领域古籍原文，版权安全）
  - 诗经 305 篇（国风 / 小雅 / 大雅 / 颂）
  - 唐诗 376 首（《唐诗三百首》全集 + 春江花月夜、长恨歌、琵琶行等名篇补遗）
  - 宋词 281 首（《宋词三百首》全集 + 满江红等名篇）
  - 汉魏乐府 15 首（曹操、曹植、《古诗十九首》、木兰诗、敕勒歌等）
  - 元曲 4 首（天净沙·秋思、山坡羊·潼关怀古等）
  - 宋诗 14 首（陆游、苏轼、王安石、杨万里、文天祥等）
  - 明清诗 5 首（于谦、郑燮、龚自珍、纳兰性德等）
- 正文约 10 万字，全部内嵌在 index.html 中，**离线可读，双击即用**
- 首页 / 诗歌库 / 收藏 / 我的四大入口
- 本地全文搜索：编号、标题、作者、正文
- 标签筛选：诗经 / 唐诗 / 宋词 / 宋诗 / 乐府 / 汉魏 / 元曲 / 明清
- 收藏、最近阅读持久化
- 用户诗歌：添加、编辑、删除（写入 IndexedDB，刷新不丢）
- 我的笔记：每首诗歌单独保存
- 阅读设置：字体大小、行距、深色阅读
- 浏览器原生朗读（设备/浏览器支持时）
- 分享 / 复制诗歌文本
- JSON 完整备份与恢复
- JSON / TXT 批量导入
- Service Worker 离线缓存（在 HTTPS 或 localhost 环境安装 PWA 时生效）

## 数据来源与版权说明

- 正文来自公开的古籍文本（chinese-poetry 开源数据集，MIT 许可），
  均为作者去世已久的公有领域作品，可自由使用、导入、分享。
- 唐诗三百首原始数据为繁体，已统一转换为简体。
- 请勿把受版权保护的现代诗歌或歌词导入本应用。

## 双击运行

直接解压后双击 `index.html` 即可使用全部功能（数据已内嵌，无需网络）。

## 在 iPhone 上使用

### 方式一（推荐）：部署成网站，添加到主屏幕

1. 打开 netlify.com/drop（或 GitHub Pages / Cloudflare Pages 等免费静态托管），
   把整个文件夹拖入，约 1 分钟生成一个 https 网址。
2. iPhone 用 Safari 打开该网址。
3. 点分享按钮 → 「添加到主屏幕」。
4. 主屏出现「诗经集」图标，像 App 一样使用；Service Worker 缓存后断网也能用。

### 方式二（最快）：直接传文件

1. 把 `upgrade_work.zip` 通过 AirDrop / 微信文件传输助手发到 iPhone。
2. 用「文件」App 打开并解压。
3. 点 `index.html`，Safari 会自动打开，直接阅读（数据内嵌，无需网络）。
   注意：此方式无主屏图标，收藏 / 笔记在本地文件方式下持久化可能不稳定。

## 构建说明

- `data/songs.json`：1000 首诗歌数据（应用实际读取的源数据）。
- `build.py`：把 songs.json 内嵌进 index.html 的构建脚本。
- `build_songs.py`：数据源合并脚本（记录 1000 首的组装方式）。
